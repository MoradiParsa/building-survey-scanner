First time? Set up the "Apple OCR Paste" Shortcut →
  1. Open the Shortcuts app on your iPhone.
  2. Tap + to create a new shortcut and name it "Apple OCR Paste."
  3. Add the action Take Photo (or Select Photos to use one you already took).
  4. Add the action Extract Text from Image — this is Apple's built-in Live Text recognition, fully on-device.
  5. Add the action Copy to Clipboard.
  6. Optional: add the shortcut to your Home Screen or the Share Sheet for one-tap access.
  7. Run it on a suite plaque, then come back here, tap the box above, and paste.
